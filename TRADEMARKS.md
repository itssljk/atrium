- **Attribution**: Refer to the project by name to identify it as the origin of

  reference is truthful and not misleading.
- **Verbatim forks with credit**: Redistribute unmodified copies, keeping the
  original name and branding intact, as required by the license's

- **Nominative fair use**: Describe or link to the project (e.g. a blog post,

- Using the Marks as part of your own product, domain, store listing, or
  extension name (e.g. "Atrium Tabs Pro", "Atrium Launcher").
- Using the Marks in a way that implies endorsement, sponsorship, or
  affiliation with the project.

## Renaming your fork

If you distribute a modified version, please rebrand it (name, logo, and
icons) and remove or replace the project's Marks. Forks must also avoid
reserved font names per the bundled fonts' SIL Open Font License 1.1 terms
(see `public/fonts/*-OFL.txt`).
